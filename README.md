# Songmilim: שליטה בבית ובמוזיקה

אפליקציה לאייפון ולאייפד שמחברת במקום אחד את:

| | מה אפשר לעשות |
|---|---|
| 🏠 **Apple Home** | אורות, שקעים, תריסים, מנעול (פתיחה רק עם Face ID) וסצנות |
| 🔊 **Sonos** | כל החדרים, מה מתנגן, הפעלה ועצירה, עוצמה לקבוצה ולכל חדר, צירוף חדרים יחד, המועדפים של Sonos |
| 🎵 **Apple Music** | הפלייליסטים שלך, חיפוש, ניגון והעברה לרמקולים ב-AirPlay |
| 🟢 **Spotify** | הפלייליסטים שלך, חיפוש, ניגון על כל רמקול (כולל Sonos) דרך Spotify Connect |
| 🔵 **Shazam** | "מה השיר הזה?" וחיפוש מיידי של השיר |
| 🗣️ **Siri** | "עצור את המוזיקה ב-Songmilim", "המשך לנגן בחדר", "קבע עוצמה בחדר" |
| 🅰️ **Alexa** | דרך Matter ו-Sonos (הסבר בהמשך) |

## אבטחה: איך זה בנוי

- **אין שרת.** הכל רץ על המכשיר שלך, כך שאין שרת שאפשר לפרוץ אליו או מסד נתונים שאפשר לגנוב.
- **Apple Home.** התקשורת מוצפנת מקצה לקצה על ידי אפל. אפליקציה מקבלת גישה רק אחרי שאישרת אותה.
- **Sonos מקומי בלבד.** הפקודות נשלחות ישירות לרמקולים ברשת הביתית. הקוד חוסם שליחה לכל כתובת שאינה כתובת של רשת ביתית.
- **Spotify ב-OAuth + PKCE.** ההתחברות נעשית בדף הרשמי של Spotify. אין באפליקציה סיסמה ואין "סוד".
- **Keychain.** מפתחות הגישה נשמרים מוצפנים, רק על המכשיר הזה, ולא מסונכרנים ל-iCloud.
- **Face ID.** האפליקציה ננעלת בכל יציאה, ופתיחת מנעול דורשת תמיד Face ID.
- **בלי כתובת חזרה פתוחה.** האפליקציה לא רושמת כתובת (URL scheme) שאפליקציות אחרות יכולות לפתוח.

> אין מערכת שאי אפשר לפרוץ אליה ב-100%. החוליה החלשה היא בדרך כלל הסיסמאות שלך: הפעל אימות דו-שלבי ב-Apple ID, ב-Spotify, ב-Sonos ובאמזון, והשתמש בסיסמה חזקה לרשת ה-Wi‑Fi.

## התקנה על המק (פעם אחת, בערך 20 דקות)

### 1. כלים
```bash
brew install xcodegen
```
(אם אין לך Homebrew: https://brew.sh)

### 2. חשבון מפתח של אפל
1. הירשם ל-[Apple Developer Program](https://developer.apple.com/programs/). העלות היא 99$ לשנה, והחשבון נדרש בשביל HomeKit.
2. מצא את ה-**Team ID** שלך: developer.apple.com ← Account ← Membership.

### 3. Spotify
1. היכנס ל-https://developer.spotify.com/dashboard וצור אפליקציה (Create app).
2. ב-**Redirect URI** הוסף בדיוק: `songmilim://spotify-callback`
3. סמן **Web API**.
4. העתק את ה-**Client ID**. את ה-Client Secret לא צריך.
5. אם מי שמשתמש באפליקציה הוא לא בעל החשבון: Settings ← User Management, והוסף את המייל שלו.

### 4. הגדרות אישיות
```bash
cp Config/Secrets.example.xcconfig Config/Secrets.xcconfig
```
פתח את `Config/Secrets.xcconfig` ומלא:
- `APP_BUNDLE_ID`: מזהה ייחודי, למשל `com.adam.songmilim`
- `APP_TEAM_ID`: ה-Team ID מסעיף 2
- `SPOTIFY_CLIENT_ID`: מסעיף 3

הקובץ הזה לא נשמר ב-git.

### 5. יצירת הפרויקט והרצה
```bash
xcodegen generate
open Songmilim.xcodeproj
```
ב-Xcode: חבר את האייפון, בחר אותו למעלה ולחץ ▶️.

### 6. הפעלת MusicKit ו-ShazamKit (פעם אחת)
אחרי ההרצה הראשונה Xcode יוצר את ה-App ID. עכשיו:
1. היכנס ל-developer.apple.com ← Certificates, IDs & Profiles ← Identifiers ובחר את ה-App ID שלך.
2. בלשונית **App Services** סמן את **MusicKit** ואת **ShazamKit** ושמור.

## שימוש

- **Sonos:** הטלפון צריך להיות על אותה רשת Wi‑Fi. בפתיחה הראשונה אשר "גישה לרשת המקומית". אם הרמקולים לא נמצאים, הזן כתובת IP של אחד מהם בלשונית "חיבורים".
- **המועדפים של Sonos:** כל מה שתסמן כמועדף באפליקציית Sonos, כמו פלייליסט מ-Spotify או מ-Apple Music או תחנת רדיו, יופיע במסך החדר ויתנגן בלחיצה.
- **Apple Music על Sonos:** לחץ על כפתור ה-AirPlay במסך המוזיקה ובחר את הרמקול.
- **Spotify על Sonos:** בחר את הרמקול ברשימה "נגן על". אם רמקול חסר ברשימה, נגן עליו פעם אחת מאפליקציית Spotify.
- **Siri:** הפקודות מופיעות גם באפליקציית "קיצורים". משם אפשר להוסיף אותן לאוטומציות, למשל "כשאני מגיע הביתה, נגן בסלון".

## Alexa

לאמזון אין ממשק רשמי שמאפשר לאפליקציה אחרת לשלוט ב-Alexa. חיבורים לא רשמיים עובדים דרך שמירה של סיסמת אמזון שלך, ולכן **בכוונה לא השתמשנו בהם**. הדרכים הבטוחות לחבר את Alexa:

1. **Matter:** אם המנעול תומך ב-Matter, אפשר לחבר אותו גם ל-Apple Home וגם ל-Alexa. ב-Apple Home: הגדרות האביזר ← "הפעל מצב צימוד", ואז הוסף אותו באפליקציית Alexa.
2. **Sonos עם Alexa מובנית:** באפליקציית Sonos ← הוספת שירות קולי ← Amazon Alexa.
3. **מוזיקה ב-Alexa:** באפליקציית Alexa ← הגדרות ← מוזיקה, חבר את Spotify ואת Apple Music.

**בעתיד:** אפשר לבנות "מיומנות" (Skill) רשמית של Alexa, כך ש-Alexa תשלוט ישירות בפעולות של האפליקציה. זה דורש שרת קטן בענן של אמזון, ולכן הוא לא נכלל בגרסה הראשונה.
